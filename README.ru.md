# Dexty Twitch Notifier

Компактная программа для Windows: следит за стримами Twitch и при желании отправляет уведомления в Telegram.

[English](README.md) · [Инструкция](USER_GUIDE.md)

Версия **1.0.0** подготовлена для тестирования владельцем. Полный вход в Twitch, доставка Telegram, установка на чистую систему и автозагрузка ещё требуют проверки перед стабильным публичным релизом.

## Возможности

- Английский и русский интерфейс и настройка.
- Вход в Twitch через браузер без ключей разработчика у пользователя.
- Добавление логинов и ссылок на каналы; стримеры в эфире идут первыми.
- Открытие Twitch по клику на строку, компактное окно из трея.
- Пауза, ручное обновление, редактирование списка.
- Необязательные уведомления через собственного Telegram-бота, тест отправки и поиск личного Chat ID.
- Необязательная автозагрузка Windows. Закрытие окна сворачивает программу в трей; для завершения выберите «Выход».

## Установка

Скачайте установщик из Releases. Python пользователю не нужен. Выберите язык установщика, затем язык программы на экране настройки.

Предварительная версия устанавливается отдельно от прежней и хранит настройки в `%LOCALAPPDATA%\DextyTwitchNotifier`. Не включайте уведомления одновременно в двух версиях для одних и тех же каналов, чтобы не получать дубли.

## Данные

Программа обращается к Twitch и, если включён, Telegram. Аналитика не реализована. Личные токены и настройки хранятся локально в JSON без шифрования. Не публикуйте эти файлы. Удаление программы сохраняет настройки для переустановки; для полного удаления данных закройте программу и удалите только папку `DextyTwitchNotifier`.
